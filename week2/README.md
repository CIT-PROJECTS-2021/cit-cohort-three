# Week 2: Control Flow, Operators, and Data Types

This week moves from simple statements to logic and collections. You will learn
how to control program flow, compare values, and store multiple items in data
structures.

## Learning Goals
- Use `if`, `for`, and `while` to control program flow.
- Understand common operators and how they affect expressions.
- Work with lists, tuples, strings, sets, and dictionaries.
