# Python Operators

Operators are special symbols that perform computations on values (operands).

```python
result = 5 + 3  # 8
```

## Operator Groups
- Arithmetic
- Comparison
- Logical
- Assignment
- Identity
- Membership
- Bitwise

## Notes
- Some operators return numbers, others return booleans.
- Operator precedence affects how expressions are evaluated.
