# The `while` Statement (Summary)

The `while` statement repeats a block of code while a condition remains true.
For the full explanation and examples, see the main note:

[Go to the `while` loops note](/week2/control_flow/while_loops/README.md)

## Quick Example
```python
count = 0
x = 32

while x > 0:
    x //= 2
    count += 1

print("The approximate log2 is", count)
```
