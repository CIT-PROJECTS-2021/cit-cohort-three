# Quiz Week 4

1. Create a 2‑D array and slice out the second number in the second column.
2. Write a Python program to sort array elements in ascending/descending order.
3. Write a Python program to find the maximum and minimum value in a given 2‑D array.
4. Input 5 subject marks and calculate total, percentage, and grade:
   - `< 50` → Grade C  
   - `50` to `< 80` → Grade B  
   - `>= 80` → Grade A
5. Fetch only email IDs from a text file with fields: Name, Mobile Number, Roll Number, Email ID.
6. Write `check_speed(speed)`:
   - If speed < 70 → print `"Ok"`.
   - For every 5 km/h above 70 → one point.
   - If points > 12 → print `"License suspended"`.
7. Write `show_stars(rows)`. For `rows = 5`:
```
*
**
***
****
*****
```
8. Print numbers between 2000 and 3200 (inclusive) divisible by 7 but not multiples of 5.
9. Accept comma-separated numbers and output a list and tuple:
```
['34', '67', '55', '33', '12', '98']
('34', '67', '55', '33', '12', '98')
```
10. Compute:
   `Q = sqrt((2 * C * D) / H)` with `C=50`, `H=30`, and D as comma-separated input.
11. Write a function to compute `5/0` and handle the exception.
12. Create a nested list that prints out a color and car brand.
13. **Bonus**: Create your own sorting algorithm.


## Common Mistakes
- Re-read the example and trace values step by step.
- Use small inputs to test your logic first.
- Add print statements to confirm assumptions.
