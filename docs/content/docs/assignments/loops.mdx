# Loops Practice

## Core Exercises
1. Print first 10 natural numbers using a `while` loop.
2. Calculate the sum of all numbers from 1 to a given number.
3. Print the multiplication table of a given number (e.g., 2 → 2, 4, 6, 8).
4. Display numbers from a list that meet all conditions:
   - divisible by 5
   - if > 150, skip
   - if > 500, stop the loop  
   Given `numbers = [12, 75, 150, 180, 145, 525, 50]`
5. Count total number of digits in a number using a `while` loop (e.g., `4673453`).
6. Display numbers from `-10` to `-1` using a `while` loop.

## Revision Questions
1. Print all numbers from 1 to 100.
2. Print all numbers from 1 to 100 except multiples of 3.
3. Print all alphabets from `a` to `z`.
4. Given a list of numbers, print those divisible by 5 and 7.
5. Using a `for` loop, create this pattern:
```
*
* *
* * *
* * * *
```
6. Reverse a number using a `while` loop (e.g., `12345` → `54321`).
7. Find the sum of even numbers using a `while` loop.
8. Find the factorial of a number using a `while` loop.

<Callout type="tip">
Try solving each problem without looking up solutions. Struggle is part of
learning.
</Callout>


## Common Mistakes
- Re-read the example and trace values step by step.
- Use small inputs to test your logic first.
- Add print statements to confirm assumptions.
