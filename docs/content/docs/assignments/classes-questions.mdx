# Classes Questions

1. Create a `CreditCard` class with card number, expiration date, and security code. Add a method to print them. Create an instance and call the method.
2. Create `Animal` and `Dog` classes. Make `Dog` inherit from `Animal`. Add a `bark` method. Create an instance and call `bark`.
3. Create a `Queue` class with `enqueue`, `dequeue`, and `size`.
4. Create a `Stack` class with `push`, `pop`, and `size`.
5. Create a `Person` class with `name`, `age`, `address`. Methods: `eat`, `sleep`, `work`.
6. Create an `Employee` class with `name`, `age`, `salary`. Methods: `eat`, `sleep`, `work`.  
   Create a subclass `Programmer` with `programming_language` and method `code`.
7. Create a `Vehicle` class with `make`, `model`, `year`. Methods: `start`, `stop`, `drive`.  
   Create a subclass `Car` with `color` and method `park`.
8. Create an `Animal` class with `name`, `color`, `age`. Methods: `eat`, `sleep`, `make_sound`.  
   Create a subclass `Dog` with `breed` and method `bark`.
9. Create a class of your choice with at least 3 attributes and 3 methods. Include a static method. Implement polymorphism, encapsulation, and inheritance.


## Common Mistakes
- Re-read the example and trace values step by step.
- Use small inputs to test your logic first.
- Add print statements to confirm assumptions.
