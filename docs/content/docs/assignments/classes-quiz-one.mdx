Using classes, create a basic banking application with the following features:

1. Create a class `BankAccount` with:
   - `account_number` (string)
   - `balance` (float)
   - `owner` (string)
   - `type` (string)

2. Create a class `Bank` with:
   - `name` (string)
   - `accounts` (list of `BankAccount`)

3. Create a class `Customer` with:
   - `name` (string)
   - `accounts` (list of `BankAccount`)

4. Create a class `Transactions` with:
   - `account` (`BankAccount`)
   - `amount` (float)
   - `type` (string)

The application should:
1. Create a `Bank`
2. Create a `Customer`
3. Create a `BankAccount`
4. Add the account to the bank
5. Add the account to the customer
6. Print the bank
7. Print the customer
8. Print the account
9. Create a `Transaction`
10. Add the transaction to the account
