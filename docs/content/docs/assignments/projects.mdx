# Projects

<Callout type="tip">
Keep scope small. A polished, working project beats a big incomplete one.
</Callout>

## Project List
1. **Weather Program**
   - Use `requests` to fetch current weather for a city.
   - Save the city name and weather to a file.
   - Read the file and print saved entries.
   - API: `https://openweathermap.org/current`

2. **Password Generator**
   - Ask user for length and counts of letters/numbers.
   - Mix uppercase, lowercase, numbers, and symbols.
   - Minimum length: 6.

3. **Interactive Quiz**
   - Multiple choice questions.
   - User inputs letter choice.
   - Show score and correct answers at the end.

4. **Country Capitals Guessing Game**
   - Randomly pick a country and ask for the capital.
   - Track correct guesses.
   - Data source: `https://raw.githubusercontent.com/samayo/country-json/master/src/country-by-capital-city.json`

<Steps>
<Step title="Plan">
Define inputs, outputs, and a minimal feature set.
</Step>
<Step title="Build">
Implement the core flow first, then add extras.
</Step>
<Step title="Test">
Run through edge cases and fix obvious bugs.
</Step>
</Steps>

## Extension Ideas
1. Add input validation and helpful error messages.
2. Save results to a CSV or JSON file.
3. Add a simple menu so users can repeat tasks.


## Common Mistakes
- Re-read the example and trace values step by step.
- Use small inputs to test your logic first.
- Add print statements to confirm assumptions.
