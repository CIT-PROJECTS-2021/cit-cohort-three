Functions let you name a piece of behaviour. Classes let you keep that behaviour
next to the data it works on, so the two travel together.

This week is the longest in the course, and the order matters: the big idea, then
the syntax, then the four principles, then a project that uses all of them.

<Callout title="Before you start">
You need [Week 4](/docs/week4). A method is a function that lives on a class, so
everything about arguments and return values still applies.
</Callout>

## What you'll learn

- Why bundling data with behaviour makes programs easier to change
- Define a class, create objects from it, and write `__init__`
- Apply encapsulation, abstraction, inheritance, and polymorphism
- Recognise when "has-a" beats "is-a"
- Build a small system from several classes that talk to each other

## The four pillars

Read these in order. Encapsulation and abstraction are about a single class;
inheritance and polymorphism are about how several classes relate.
