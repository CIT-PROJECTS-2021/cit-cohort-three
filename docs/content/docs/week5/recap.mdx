## Checklist
- I can explain the difference between a class and an object.
- I can write `__init__` and say what `self` refers to.
- I can name the four pillars and give an example of each.
- I can subclass a class and override one of its methods.
- I can say why composition is usually the safer default.

## Try This
1. Write a `BankAccount` class with `deposit`, `withdraw`, and a balance it protects.
2. Subclass it as `SavingsAccount` that adds interest.
3. Give two unrelated classes the same method name and loop over both.
4. Rewrite one inheritance relationship you wrote above using composition instead.
5. Work through the [OOP Project](/docs/week5/oop-project) without reading ahead.
