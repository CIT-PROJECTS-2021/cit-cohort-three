## Question 1
What is the result of the following code?

```python
import pandas as pd
import numpy as np

df = pd.DataFrame(np.random.randn(5, 3), columns=['col1', 'col2', 'col3'])
df.apply(lambda x: x.max() - x.min())
```

## Common Mistakes
- Forgetting to inspect `df.head()` after loading.
- Mixing up row and column selection.
- Mutating data without making a copy when needed.
