# Pandas Quiz

<Callout type="info">
Pandas is built on NumPy and is great for tabular data.
</Callout>

## Quick Tutorial
```python
import pandas as pd

df = pd.DataFrame({
    "name": ["Ada", "Grace", "Linus"],
    "score": [95, 88, 76],
})
print(df.head())
```
**Expected output**
```
    name  score
0    Ada     95
1  Grace     88
2  Linus     76
```

### Loading JSON
```python
df = pd.read_json("https://jsonplaceholder.typicode.com/albums")
print(df.head())
```
**Expected output**
```
   userId  id                                     title
0       1   1                                     quidem
1       1   2                                 sunt qui
2       1   3                          omnis laborum
3       1   4                       non esse culpa
4       1   5  eaque aut omnis a
```

### Filtering
```python
high_scores = df[df["score"] >= 80]
```

### Aggregation
```python
print(df["score"].mean())
```
