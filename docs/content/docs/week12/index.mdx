Python lists are fine for a hundred items. For a hundred thousand — or for
anything shaped like a table — you want NumPy and Pandas.

<Callout title="Before you start">
You need [Lists](/docs/week2/lists), [Dictionaries](/docs/week2/dictionaries),
and [CSV and JSON](/docs/week4/csv-and-json).
</Callout>

## What you'll learn

- Create, reshape, and iterate NumPy arrays
- Build Pandas Series and DataFrames from lists, dicts, CSV, and JSON
- Select rows and columns without writing loops
- Explore a dataset you've never seen before
