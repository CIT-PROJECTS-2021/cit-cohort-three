# Numpy Array Quiz

<Callout type="info">
Use NumPy for fast numerical operations on arrays.
</Callout>

## Quick Tutorial
NumPy arrays support fast, element‑wise operations.

```python
import numpy as np

a = np.array([1, 2, 3])
b = np.array([4, 5, 6])
print(a + b)  # [5 7 9]
```

### Reshaping
```python
zeros = np.zeros(10)
reshaped = zeros.reshape(2, 5)
print(reshaped)
```

### Indexing and Slicing
```python
a = np.array([[1, 2, 3], [4, 5, 6]])
print(a[0, 1])  # 2
print(a[:, 1])  # column 1
```
**Expected output**
```
2
[2 5]
```

### Aggregations
```python
data = np.array([1, 2, 3, 4, 5])
print(data.mean())
print(data.max())
```
**Expected output**
```
3.0
5
```

- Reshaping to an incompatible shape.
- Forgetting that NumPy uses zero‑based indexing.
