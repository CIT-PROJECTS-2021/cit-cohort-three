## Question 1
What is the result of the following code?

```python
import numpy as np
a = np.array([1, 2, 3])
b = np.array([4, 5, 6])
c = a + b
print(c)
```

## Common Mistakes
- Confusing element‑wise addition with matrix multiplication.
- Reshaping to an incompatible shape.
- Forgetting that NumPy uses zero‑based indexing.
