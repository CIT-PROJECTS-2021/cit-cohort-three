## Checklist
- I can map create, read, update, and delete onto HTTP methods.
- I can define CRUD endpoints in Flask.
- I know which status code to return, and when.
- I can validate input and return a useful error.
- I can model a relationship between users and their tasks.
- I store passwords hashed, never in plain text.

## Try This
1. Create a `POST /tasks` endpoint that returns 201 with the new task.
2. Add validation for required fields and return 400 when one is missing.
3. Return 404 when the requested item doesn't exist.
4. Add registration and login, hashing the password on the way in.
5. Drive every endpoint from `curl` before you trust it.
