Week 9 was the technique. This week is the project: a scraper that runs on a
schedule, stores what it finds, and serves it back out.

<Callout title="Before you start">
You need [Web Scraping](/docs/week9/web-scraping) and
[Classes](/docs/week3/classes) — SQLAlchemy models are classes.
</Callout>

## What you'll learn

- Parse XML feeds with `lxml`
- Model rows as Python classes with SQLAlchemy
- Avoid inserting the same article twice
- Serve stored data from a small Flask app
- Run the scraper on a schedule
