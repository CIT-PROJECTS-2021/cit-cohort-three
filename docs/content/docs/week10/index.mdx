Most of the data you'll ever want is behind an API, and most of the software
you'll ever write will expose one. This week you build both sides of that idea:
resources, methods, status codes, and auth.

<Callout title="Before you start">
You need [Classes](/docs/week5/classes) for the SQLAlchemy models,
[CSV and JSON](/docs/week6/csv-and-json) for the payloads, and
[Hash Functions](/docs/week9/hash-functions) for storing passwords.
</Callout>

## What you'll learn

- Map CRUD operations onto HTTP methods and status codes
- Define models with SQLAlchemy and serialise them to JSON
- Test endpoints with `curl` and an HTTP client
- Add registration and login, storing passwords the way Week 9 taught you
