A **queue** is a data structure where the first item added is the first item
removed. This is called **FIFO**: First‑In, First‑Out.

## Key Ideas
- **Enqueue**: add to the back
- **Dequeue**: remove from the front
- **Peek**: look at the front without removing

## Real‑World Analogy
Think of a line at a checkout counter: the first person in line is served first.

## Example in Python
Use `collections.deque` for efficient queue operations.

```python
from collections import deque

queue = deque()
queue.append("A")    # enqueue
queue.append("B")
queue.append("C")

front = queue.popleft()  # dequeue -> "A"
print(front)
print(list(queue))       # ["B", "C"]
```

## Use Cases
- Task scheduling
- Print job queues
- Message processing systems

## Rules

1. **First in, first out.** Items leave in the order they arrived.
2. **Enqueue and dequeue happen at opposite ends.**
3. **Dequeuing an empty queue is an error.** Check first, or catch it.
4. **Use `collections.deque`, not a list.** `deque.popleft()` is O(1); `list.pop(0)` is O(n).
5. **`append()` adds to the right and `popleft()` removes from the left** — mixing the ends turns your queue into a stack.
6. **A queue exposes only its two ends.** No indexing, no searching.

## Common Mistakes
- Using a list with `pop(0)` for large queues (slow)
- Forgetting to check if the queue is empty before dequeue
