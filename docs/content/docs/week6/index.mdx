Everything you've written so far disappears when the program ends. This week your
programs start keeping things.

Exceptions come first, because file work is where errors stop being hypothetical.
A missing file, a locked file, a file in the wrong encoding: all of these are
normal, and all of them raise.

<Callout title="Before you start">
You need [Week 4](/docs/week4) for functions and [Week 3](/docs/week3) for the
collections you'll be writing out as CSV and JSON.
</Callout>

## What you'll learn

- Catch errors deliberately with `try` / `except` / `else` / `finally`
- Raise your own exceptions when a caller has done something wrong
- Open files safely with `with`, and pick the right mode
- Build and manipulate paths with `pathlib` instead of string concatenation
- Read and write the two formats you'll meet everywhere: CSV and JSON
