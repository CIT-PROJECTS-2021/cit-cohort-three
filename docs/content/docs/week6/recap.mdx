# Week 6 Recap

## Checklist
- I can explain LIFO vs FIFO.
- I can implement a basic stack and queue.
- I understand what a linked list node is.
- I can describe what a sorting algorithm does.
- I can use `list.sort()` and `sorted()`.

## Try This
1. Implement a stack and queue from scratch.
2. Trace one pass of bubble sort on paper.
3. Explain why `deque` is better than `list` for queues.
