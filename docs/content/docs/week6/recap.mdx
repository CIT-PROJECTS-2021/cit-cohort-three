## Checklist
- I can catch a specific exception rather than a bare `except`.
- I know what `else` and `finally` add to a `try` block.
- I can raise an exception with a useful message.
- I can open files with `with open(...)` and explain why that's better.
- I know the difference between `r`, `w`, and `a` modes.
- I can build a path with `pathlib` and check whether it exists.
- I can read and write both CSV and JSON.

## Try This
1. Handle a `ValueError` when converting user input to `int`.
2. Read a file that doesn't exist and report it without crashing.
3. Read a file and count its lines.
4. Append a line with today's date, then read it back to confirm.
5. Load a CSV, filter the rows, and write the result out as JSON.
