A **stack** is a data structure where the last item added is the first item
removed. This is called **LIFO**: Last‑In, First‑Out.

## Key Ideas
- **Push**: add to the top
- **Pop**: remove from the top
- **Peek**: look at the top without removing

## Real‑World Analogy
Think of a stack of plates. You put a new plate on top, and when you take one,
you take the top plate first.

## Example in Python
```python
stack = []

stack.append("A")  # push
stack.append("B")
stack.append("C")

top = stack.pop()  # pop -> "C"
print(top)
print(stack)       # ["A", "B"]
```

## Use Cases
- Undo/redo in editors
- Browser back/forward history
- Expression evaluation (e.g., parentheses matching)

## Rules

1. **Last in, first out.** The only reachable element is the one added most recently.
2. **Push and pop must operate on the same end.** With a Python list that's `append()` and `pop()` — both O(1).
3. **Popping or peeking an empty stack is an error.** Check `is_empty()` first, or catch `IndexError`.
4. **`peek()` returns the top without removing it; `pop()` removes and returns it.**
5. **Never index into the middle of a stack.** If you need that, you wanted a [list](/docs/week2/lists).
6. **`list.pop(0)` makes it a slow queue, not a stack.** Pop from the end.

## Common Mistakes
- Using `pop(0)` (that’s a queue behavior, and it’s slow)
- Forgetting to check if stack is empty before popping
