Not every site has an API. Web scraping is how you get structured data out of
pages built for humans, and it's deliberately placed after
[Week 10](/docs/week10) so you can see it for what it is: the fallback, not the
first choice.

The week runs in two halves. First the technique, then a real project that puts
it behind the Flask and SQLAlchemy you already know.

<Callout title="Before you start">
You need [Lists](/docs/week3/lists), [Dictionaries](/docs/week3/dictionaries),
[Functions](/docs/week4/functions),
[File Handling](/docs/week6/file-handling) to save what you collect, and
[Week 10](/docs/week10) for the Flask half of the project.
</Callout>

## What you'll learn

- Fetch a page with `requests` and parse it with BeautifulSoup
- Find the elements you want using tags, classes, and CSS selectors
- Walk through paginated listings
- Parse XML feeds with `lxml`
- Store what you find without inserting the same article twice
- Scrape without getting blocked, and without getting sued
