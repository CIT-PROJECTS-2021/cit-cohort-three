You used Flask to serve data in Week 10. This week you learn to design the
interface deliberately: resources, methods, status codes, and auth.

<Callout title="Before you start">
You need [Week 10](/docs/week10), or at least a working Flask + SQLAlchemy setup.
</Callout>

## What you'll learn

- Map CRUD operations onto HTTP methods and status codes
- Define models and serialise them to JSON
- Test endpoints with `curl` and an HTTP client
- Add registration and login to an API
