This is a simple TODO API built with Python (Flask) and SQLite.

<Callout type="tip">
Start with one model and one endpoint. Get it working, then expand.
</Callout>

## Goals
- Define a basic Task model
- Create CRUD endpoints
- Persist data with SQLite

## 1) Install Dependencies
```bash
pip install flask sqlalchemy
```

## 2) Define the model
```python
from sqlalchemy import create_engine, Column, Integer, String, Boolean
from sqlalchemy.orm import declarative_base

Base = declarative_base()

class Task(Base):
    __tablename__ = "tasks"
    id = Column(Integer, primary_key=True)
    title = Column(String(200))
    done = Column(Boolean, default=False)
```

## 3) Create the database
```python
engine = create_engine("sqlite:///todo.db")
Base.metadata.create_all(engine)
```

## 4) Build the API
```python
from flask import Flask, request, jsonify
from sqlalchemy.orm import Session

app = Flask(__name__)

@app.get("/tasks")
def list_tasks():
    with Session(engine) as session:
        tasks = session.query(Task).all()
        return jsonify([{"id": t.id, "title": t.title, "done": t.done} for t in tasks])

@app.post("/tasks")
def create_task():
    payload = request.json or {}
    if "title" not in payload:
        return jsonify({"error": "title is required"}), 400
    with Session(engine) as session:
        task = Task(title=payload["title"])
        session.add(task)
        session.commit()
        return jsonify({"id": task.id, "title": task.title, "done": task.done}), 201
```
**Expected response**
```json
{"id": 1, "title": "Read docs", "done": false}
```

## 5) Get, Update, Delete
```python
@app.get("/tasks/<int:task_id>")
def get_task(task_id):
    with Session(engine) as session:
        task = session.get(Task, task_id)
        if not task:
            return jsonify({"error": "not found"}), 404
        return jsonify({"id": task.id, "title": task.title, "done": task.done})

@app.put("/tasks/<int:task_id>")
def update_task(task_id):
    payload = request.json or {}
    with Session(engine) as session:
        task = session.get(Task, task_id)
        if not task:
            return jsonify({"error": "not found"}), 404
        task.title = payload.get("title", task.title)
        task.done = payload.get("done", task.done)
        session.commit()
        return jsonify({"id": task.id, "title": task.title, "done": task.done})

@app.delete("/tasks/<int:task_id>")
def delete_task(task_id):
    with Session(engine) as session:
        task = session.get(Task, task_id)
        if not task:
            return jsonify({"error": "not found"}), 404
        session.delete(task)
        session.commit()
        return jsonify({"status": "deleted"})
```
**Expected response**
```json
{"status": "deleted"}
```

## Rules

1. **Match the HTTP method to the action:** `GET` read, `POST` create, `PUT`/`PATCH` update, `DELETE` remove.
2. **`GET` must not change data.** Anything that modifies state needs a different method.
3. **Return the right status code:** `200` OK, `201` Created, `204` No Content, `400` Bad Request, `401` Unauthorized, `404` Not Found, `500` Server Error.
4. **Return JSON, and let Flask set the content type** by returning a dict or using `jsonify`.
5. **Validate every incoming field before touching the database**, and return `400` with a message rather than letting it raise.
6. **A missing resource is `404`, not an empty `200`.**
7. **URLs name resources, not actions.** `/todos/1`, not `/getTodo?id=1`.
8. **Never build SQL by string formatting.** Use the ORM or parameterised queries.
9. **Never return password hashes or secrets** in a response body.

## Common Mistakes
- Forgetting `Content-Type: application/json` when sending JSON.
- Not handling missing tasks (return 404).
- Returning SQLAlchemy objects directly (not JSON).
