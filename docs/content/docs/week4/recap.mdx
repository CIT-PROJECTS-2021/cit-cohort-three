# Week 4 Recap

## Checklist
- I can open files with `with open(...)`.
- I know the difference between `r`, `w`, and `a` modes.
- I can read full files and line by line.
- I can append to a file safely.

## Try This
1. Read a file and count its lines.
2. Append a new line with today’s date.
3. Read the file again and confirm the change.
