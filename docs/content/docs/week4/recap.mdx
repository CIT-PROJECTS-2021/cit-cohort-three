## Checklist
- I can define a function and call it with arguments.
- I know the difference between returning a value and printing one.
- I can give a parameter a default and call it by keyword.
- I know what `*args` and `**kwargs` collect.
- I can write a recursive function with a base case.
- I can move a function into another file and import it.

## Try This
1. Write a function that returns the larger of two numbers.
2. Write `greet(name, greeting="Hello")` and call it both ways.
3. Write a function that accepts any number of numbers and returns their total.
4. Write factorial recursively, then again with a loop.
5. Move two of these into `helpers.py` and import them from a second file.
