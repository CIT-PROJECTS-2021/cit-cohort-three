So far your programs have been one long script. A function is the first tool
Python gives you for naming a piece of work and calling it from anywhere, and a
module is how you move that function out of the way once it's written.

<Callout title="Before you start">
You need [Week 2](/docs/week2) for the logic you'll be wrapping up, and
[Week 3](/docs/week3) because most functions take a collection in or hand one
back.
</Callout>

## What you'll learn

- Define a function, pass it arguments, and return a value
- Tell positional, keyword, default, `*args`, and `**kwargs` apart
- Write a one-line `lambda` and know when not to
- Solve a problem recursively, with a base case that stops it
- Split code across files and import it back
