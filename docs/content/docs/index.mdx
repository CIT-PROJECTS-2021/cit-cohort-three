# CIT Python Cloud Software Engineering

Welcome to the course documentation. This is a structured, beginner‑friendly path
to Python and software engineering fundamentals with hands‑on practice each week.

## Course Objectives

By the end of this course, you will:

- Master Python programming fundamentals and advanced concepts
- Understand Object-Oriented Programming (OOP) principles
- Work with data structures and algorithms
- Learn file handling and data manipulation
- Explore cryptography and web scraping
- Prepare for AWS and Python certifications

## Course Structure

The course is organized into weekly modules. Use the sidebar to jump into any
week, or start from Week 1 and follow in order.
