A twelve-week course in Python and software engineering fundamentals, with
hands-on practice every week. Everything the cohort covered is here: notes,
examples, exercises, quizzes, and projects.

<Callout title="New here?">
Read [Start Here](/docs/start-here) first. Two minutes on how these notes are
organised. Then [set up your machine](/docs/setup) and begin
[Week 1](/docs/week1).
</Callout>

## What you'll be able to do

By the end of the course you will:

- Write Python confidently, from data types and control flow to functions and error handling
- Model problems with classes and apply the four OOP principles
- Implement the core data structures and sorting algorithms from scratch
- Read and write files, CSV, and JSON
- Build APIs backed by a database, and scrape the sites that don't have one
- Analyse data with NumPy and Pandas
- Ship a complete project of your own

## How to use these notes

<Steps>
<Step title="Set up your machine">
Install Python and an editor. [Set Up Your Machine](/docs/setup) walks through
it in about twenty minutes.
</Step>
<Step title="Follow the weeks in order">
Each week's Overview page lists what you need first. The **Next** link at the
bottom of every page takes you through the whole course in sequence.
</Step>
<Step title="Type every example">
Don't copy and paste. Typing it forces you to read every character.
</Step>
<Step title="Do the practice before reading on">
Every page ends with questions. They're short, and they're where the learning
actually happens.
</Step>
<Step title="Search when you're stuck">
Press ⌘K (or Ctrl+K) and type. Faster than scrolling the sidebar.
</Step>
</Steps>
