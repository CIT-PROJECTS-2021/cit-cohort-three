Functions group reusable logic into a named block.

<Callout type="info">
Think of a function as a mini‑program: inputs in, output out.
</Callout>

## Defining a Function
```python
def greet(name: str) -> None:
    """Print a friendly greeting."""
    print(f"Hello, {name}!")
```

**Parameters vs arguments**
- Parameters are the names in the function definition.
- Arguments are the values you pass when calling the function.

**Type hints (optional)**
```python
def add(a: int, b: int) -> int:
    return a + b
```

## Calling a Function
```python
greet("Paul")
```

## Return Values
```python
def absolute_value(n: int) -> int:
    if n >= 0:
        return n
    return -n

print(absolute_value(-4))  # 4
```

If you omit `return`, Python returns `None`.

**Why return values matter**
Returning values lets you reuse results in other parts of your program instead
of only printing them.

**Return vs print**
```python
def add(a, b):
    return a + b

result = add(2, 3)
print(result)  # 5
```

## Scope
```python
x = 10

def show() -> None:
    x = 5
    print(x)  # 5

show()
print(x)      # 10
```

**Global variables**
Avoid using `global` unless necessary; it makes code harder to test.

## Types of Functions
- Built-in functions (e.g., `print`, `len`)
- User-defined functions (your own)

## Rules

1. **Define with `def name(...):` and an indented body.** The body cannot be empty — use `pass`.
2. **A function must be defined before it is called** at runtime; calling it earlier raises `NameError`.
3. **Defining a function does not run it.** Only a call with parentheses does — `greet` is the function object, `greet()` calls it.
4. **Without `return`, a function returns `None`.** A bare `return` does the same.
5. **`return` exits immediately.** Code after it in the same block never runs.
6. **Function names follow the same rules as variable names** — see [Variables](/docs/week1/variables).
7. **Names assigned inside a function are local to it** and vanish when it ends. Reading an outer name is fine; rebinding one needs `global` or `nonlocal`.
8. **The number of arguments must match the parameters** or Python raises `TypeError`.

## Mini Exercises
1. Write a function `add(a, b)` that returns the sum.
2. Write a function `is_even(n)` that returns `True` or `False`.
3. Write a function that returns the maximum of three numbers.

## Common Mistakes
- Forgetting to return a value when it’s needed.
- Calling a function before it is defined.
- Mutating global variables accidentally.
