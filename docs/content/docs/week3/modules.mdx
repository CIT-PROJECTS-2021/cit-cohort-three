A module is a Python file that contains code you can reuse (functions, classes,
variables). Modules help you split large programs into manageable pieces.

<Callout type="info">
If a file ends with `.py`, it can be imported as a module.
</Callout>

## Creating a Module
`example.py`
```python
def add(a, b):
    return a + b
```

## Importing a Module
```python
import example

print(example.add(2, 3))  # 5
```

## Import Variations
```python
import math as m
from math import pi, e
```

Avoid `from module import *` because it pollutes the namespace.

**Built-in vs third‑party**
- Built‑in modules ship with Python (`math`, `random`).
- Third‑party modules are installed via `pip` (e.g., `requests`).

**Local module example**
```python
# utils.py
def greet(name):
    return f"Hi {name}"
```

```python
# main.py
import utils
print(utils.greet("Ada"))
```

**Expected output**
```
Hi Ada
```

## Module Search Path
Python looks in:
- the current directory
- `PYTHONPATH`
- the standard library and site-packages

You can inspect this with:
```python
import sys
print(sys.path)
```

## Rules

1. **A module is a `.py` file; its module name is the filename without the extension.**
2. **Module filenames must be valid identifiers** — letters, digits, underscores, not starting with a digit. A hyphen makes the file unimportable.
3. **Never name a file after a standard library module** (`math.py`, `random.py`, `json.py`). Yours shadows the real one.
4. **A module's top-level code runs once, on first import.** Later imports reuse the cached module.
5. **Python searches `sys.path`**, starting with the script's own directory. A module that isn't there raises `ModuleNotFoundError`.
6. **`import x` requires `x.name`; `from x import name` brings the name in directly.**
7. **Avoid `from x import *`.** It hides where names came from and silently overwrites existing ones.
8. **Guard script-only code with `if __name__ == "__main__":`** so importing the file doesn't run it.
9. **Circular imports fail.** If two modules import each other, move the shared part into a third.

## Mini Exercises
1. Create `math_tools.py` with a function `square(n)`.
2. Import it and call `square(5)` from another file.
3. Rename the module import using `as` and call it again.

## Common Mistakes
- Naming your file `math.py` or `random.py` (shadows standard modules).
- Forgetting to save the file before importing.
- Using `import *` and causing name clashes.
