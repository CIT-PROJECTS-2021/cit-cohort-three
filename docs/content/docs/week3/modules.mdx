# Modules

A module is a Python file that contains code you can reuse (functions, classes,
variables). Modules help you split large programs into manageable pieces.

<Callout type="info">
If a file ends with `.py`, it can be imported as a module.
</Callout>

## Creating a Module
`example.py`
```python
def add(a, b):
    return a + b
```

## Importing a Module
```python
import example

print(example.add(2, 3))  # 5
```

## Import Variations
```python
import math as m
from math import pi, e
```

Avoid `from module import *` because it pollutes the namespace.

**Built-in vs third‑party**
- Built‑in modules ship with Python (`math`, `random`).
- Third‑party modules are installed via `pip` (e.g., `requests`).

**Local module example**
```python
# utils.py
def greet(name):
    return f"Hi {name}"
```

```python
# main.py
import utils
print(utils.greet("Ada"))
```

**Expected output**
```
Hi Ada
```

## Module Search Path
Python looks in:
- the current directory
- `PYTHONPATH`
- the standard library and site-packages

You can inspect this with:
```python
import sys
print(sys.path)
```

## Common Mistakes
- Naming your file `math.py` or `random.py` (shadows standard modules).
- Forgetting to save the file before importing.
- Using `import *` and causing name clashes.
