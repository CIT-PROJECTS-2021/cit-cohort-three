So far your programs have been one long script. This week you learn the four
tools Python gives you for breaking a program into pieces that fit in your head.

<Callout title="Before you start">
You need [Week 2](/docs/week2) — especially [Control Flow](/docs/week2/control-flow),
[Lists](/docs/week2/lists), and [Dictionaries](/docs/week2/dictionaries).
</Callout>

## What you'll learn

- Write functions that take arguments and return values
- Model things as classes, and use the four OOP pillars
- Split code across modules and import it back
- Handle errors deliberately instead of crashing
