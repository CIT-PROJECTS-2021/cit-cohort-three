## Checklist
- I can slice a string and format one with an f-string.
- I can add to, remove from, and sort a list.
- I know why a tuple is immutable and when that's the point.
- I can use a set to remove duplicates and test membership quickly.
- I can build a dictionary and loop over its keys, values, and items.
- Given a problem, I can say which of the four collections fits.

## Try This
1. Count word frequency in a sentence using a dictionary.
2. Remove duplicates from a list while keeping the original order.
3. Write a list comprehension that squares the numbers 1 to 5.
4. Store three people as dictionaries inside a list, then print each name.
5. Explain what breaks if you try to use a list as a dictionary key.
