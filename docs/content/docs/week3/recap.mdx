# Week 3 Recap

## Checklist
- I can define and call functions with return values.
- I can import and organize code into modules.
- I understand the difference between class and object.
- I can handle basic exceptions with `try/except`.

## Try This
1. Write a function that returns the larger of two numbers.
2. Create a simple class with one method.
3. Handle a `ValueError` when converting input to `int`.
