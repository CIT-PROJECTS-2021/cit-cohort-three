Abstraction hides complex details and exposes only what users need.

## Example
```python
from abc import ABC, abstractmethod

class Vehicle(ABC):
    @abstractmethod
    def start_engine(self):
        pass

class Motorcycle(Vehicle):
    def start_engine(self):
        print("Engine started")

bike = Motorcycle()
bike.start_engine()
```

**Expected output**
```
Engine started
```

## Use Cases
- Defining required methods for subclasses
- Designing consistent interfaces

## Rules

1. **An abstract base class inherits from `ABC`** (`from abc import ABC, abstractmethod`).
2. **A class with any unimplemented `@abstractmethod` cannot be instantiated** — `TypeError` on the attempt.
3. **A subclass must implement every abstract method** before it can be instantiated.
4. **`@abstractmethod` must be the innermost decorator** when stacked with `@property` or `@staticmethod`.
5. **An abstract method may still have a body**, callable through `super()`.
6. **Abstraction defines what must exist, not how.** Put the shared contract in the base, the specifics in subclasses.

## Common Mistakes
- Instantiating abstract base classes directly
- Forgetting to implement abstract methods
