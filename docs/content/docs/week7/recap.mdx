## Checklist
- I can explain LIFO vs FIFO and name a real use for each.
- I can implement a stack with `push`, `pop`, and `peek`.
- I can implement a queue with `enqueue` and `dequeue`.
- I can describe what a linked list node holds.
- I know why `collections.deque` beats a plain list for a queue.

## Try This
1. Implement a stack and a queue from scratch, without looking at the pages.
2. Use your stack to check whether a string's brackets are balanced.
3. Build a linked list you can append to and print.
4. Time `list.pop(0)` against `deque.popleft()` on 100,000 items and explain the gap.
