This is the starting line. By the end of the week you'll be able to read a small
Python script and write one of your own.

<Callout title="Before you start">
Nothing — this is week one. If Python isn't installed yet, do
[Set Up Your Machine](/docs/setup) first (about 20 minutes).
</Callout>

## What you'll learn

- What Python is and the kinds of problems people use it for
- How indentation, comments, and docstrings shape a Python file
- How to create variables and name them well
- How integers, floats, and booleans behave
