Python is dynamically typed, which means you do not declare variable types.
A variable is created the moment you assign a value to a name.

```python
name = "Grace"
age = 37
```

<Callout type="info">
Dynamic typing means a variable can point to values of different types over
time, but you should avoid confusing changes.
</Callout>

## Good Naming
```python
total_volume = 12
user_email = "grace@example.com"
```

## Multiple Assignment
```python
x, y, z = 1, 2, 3
first_name, last_name = "Ada", "Lovelace"
```

## Reassignment and Types
```python
count = 10
count = "ten"  # valid, but try to avoid confusing changes

print(type(count))  # <class 'str'>
```



## Rules

1. **A name must start with a letter or an underscore.** `_total` and `total` are fine.
2. **A name cannot start with a digit.** `2fast` is a `SyntaxError`; `fast2` is fine.
3. **A name may contain only letters, digits, and underscores.** No spaces, hyphens, or punctuation — `user-name` is read as `user` minus `name`.
4. **A name cannot be a Python keyword.** `class`, `for`, `if`, `return`, `import`, `lambda`, `None`, `True`, `False` and the rest are reserved. Run `import keyword; print(keyword.kwlist)` for the full list.
5. **Names are case-sensitive.** `age`, `Age`, and `AGE` are three different variables.
6. **A variable must be assigned before it is used.** Reading a name that was never assigned raises `NameError`.
7. **Assignment creates the variable.** There is no separate declaration, and no type is declared — the value carries the type.
8. **The name goes on the left of `=`, the value on the right.** `5 = x` is a `SyntaxError`.

## Common Mistakes
- Using vague names like `x1`, `data2`, `temp` everywhere.
- Changing a variable’s type mid‑program and getting confused.
- Using reserved keywords as variable names.
