# Python Syntax

Python was designed for readability. It uses new lines to end statements and
indentation to define blocks of code.

<Callout type="tip">
Python uses indentation instead of `{}` braces. If indentation is wrong, your
program will not run.
</Callout>

## Indentation
Indentation is required to define blocks, such as `if` statements, loops, and
functions.

```python
if 5 > 2:
    print("Five is greater than two!")
```

## Statements and New Lines
Most statements end at the newline.

```python
name = "Ada"
print(name)
```

To continue a statement on multiple lines, wrap it in parentheses:

```python
total = (
    10
    + 20
    + 30
)
```

## Comments
Comments start with `#`. Python ignores everything after the `#` on that line.

```python
# This is a comment.
print("Hello, World!")
```

## Docstrings
Docstrings are multi-line comments used to document functions, classes, and
modules.

```python
def greet(name: str) -> None:
    """Return a friendly greeting."""
    print(f"Hello, {name}!")
```

## Common Pitfalls
- Mixing tabs and spaces (use spaces only).
- Forgetting indentation after `if`, `for`, `while`, `def`, or `class`.
- Adding extra indentation where it does not belong.


## Common Mistakes
- Using tabs in one block and spaces in another.
- Writing multiple statements on one line for beginners (hard to read).
- Forgetting the colon `:` after a header line.
