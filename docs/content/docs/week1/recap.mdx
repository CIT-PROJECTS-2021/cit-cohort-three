# Week 1 Recap

## Checklist
- I can explain what Python is and where it’s used.
- I understand indentation, comments, and docstrings.
- I can create and name variables.
- I can work with integers, floats, and booleans.

## Try This
1. Write a script that prints your name and age.
2. Convert a string to an integer and add 5.
3. Explain why `0.1 + 0.2` is not exactly `0.3`.
