Python has three main numeric types:
- `int` for whole numbers (e.g. `2`, `-5`)
- `float` for decimal numbers (e.g. `3.14`, `-0.5`)
- `complex` for complex numbers (e.g. `2+3j`)

`bool` is a subtype of `int` where `False` behaves like `0` and `True` behaves
like `1`.

<Callout type="info">
Python integers have unlimited precision, but floats can have small rounding
errors due to how computers store decimals.
</Callout>

## Integers
```python
positive_int = 2
negative_int = -2
zero = 0
```

## Booleans
```python
is_raining = True
is_cloudy = False
```

## Floats
```python
float_number = 7.0
float_number_via_function = float(7)
float_negative = -35.59
```

## Complex Numbers
```python
z = 2 + 3j
print(z.real)  # 2.0
print(z.imag)  # 3.0
```

## Common Operations
```python
a = 10
b = 3

print(a + b)  # 13
print(a - b)  # 7
print(a * b)  # 30
print(a / b)  # 3.333...
```

## Useful Built-ins
```python
print(type(5))             # <class 'int'>
print(isinstance(5, int))  # True
print(round(3.14159, 2))   # 3.14
```

## Rules

1. **`int` has unlimited precision.** Whole numbers never overflow; they grow as large as memory allows.
2. **`float` does not.** Floats are binary approximations, so `0.1 + 0.2 == 0.3` is `False`. Compare with a tolerance, or use `decimal.Decimal` for money.
3. **`/` always returns a float**, even for `6 / 3`. Use `//` for whole-number division.
4. **`//` rounds toward negative infinity**, so `-7 // 2` is `-4`, not `-3`.
5. **Division by zero raises `ZeroDivisionError`** for both `/` and `//`.
6. **`bool` is a subclass of `int`.** `True == 1` and `False == 0`, and `True + True` is `2`.
7. **Numeric types don't mix silently in output types.** `int + float` gives a `float`; converting back with `int()` truncates toward zero rather than rounding.
8. **Underscores are allowed as digit separators.** `1_000_000` is the same as `1000000`.

## Common Mistakes
- Using `/` when you want whole numbers (use `//`).
- Expecting exact results with floating point decimals.
- Forgetting that `True` and `False` act like `1` and `0`.
- `0.1 + 0.2` is not exactly `0.3` because of floating-point precision.
- Dividing two integers with `/` always returns a float.
