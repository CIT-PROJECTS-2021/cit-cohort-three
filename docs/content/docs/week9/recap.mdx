## Checklist
- I can define plaintext, ciphertext, encryption, and decryption.
- I can explain symmetric vs asymmetric cryptography.
- I know when to use hashing and when to use encryption.
- I know why MD5 and SHA-1 are no longer safe.
- I know why a password needs a slow, salted hash rather than SHA-256.

## Try This
1. Hash a string with SHA-256 using `hashlib`.
2. Explain, in one sentence, why hashing is one-way.
3. Break a Caesar cipher by trying all 25 keys.
4. Describe a real use case for asymmetric cryptography.
5. Look up what `secrets.token_hex()` does and why it isn't `random`.
