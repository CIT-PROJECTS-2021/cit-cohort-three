Not every site has an API. Web scraping is how you get structured data out of
pages built for humans.

<Callout title="Before you start">
You need [Lists](/docs/week2/lists), [Dictionaries](/docs/week2/dictionaries),
[Functions](/docs/week3/functions), and
[File Handling](/docs/week4/file-handling) to save what you collect.
</Callout>

## What you'll learn

- Fetch a page with `requests` and parse it with BeautifulSoup
- Find the elements you want using tags, classes, and CSS selectors
- Walk through paginated listings
- Save results to CSV or JSON
- Scrape without getting blocked — or sued
