Two ideas this week, and the most important thing is not to confuse them.
**Encryption** is reversible by design. **Hashing** is not.

This sits where it does for a reason: next week's API needs to store passwords,
and the only correct way to do that is with the hashing you learn here.

<Callout title="Before you start">
You need [Strings](/docs/week3/strings) and [Functions](/docs/week4/functions).
The ciphers are mostly string manipulation.
</Callout>

## What you'll learn

- How a substitution cipher turns readable text into unreadable text, and back again
- Why the ciphers you write here are *teaching tools*, not security
- What a cryptographic hash is, and the four properties that make one useful
- Where hashing shows up in software you already use: Git, passwords, checksums
