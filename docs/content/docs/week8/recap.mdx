# Week 8 Recap

## Checklist
- I can define plaintext, ciphertext, encryption, and decryption.
- I can explain symmetric vs asymmetric cryptography.
- I know when to use hashing vs encryption.
- I know why MD5 is not secure.

## Try This
1. Hash a string using SHA‑256.
2. Explain why hashing is one‑way.
3. Describe a real‑world use case for asymmetric cryptography.
