## Checklist
- I can say what a sorting algorithm does and why there is more than one.
- I can trace bubble, selection, and insertion sort on paper.
- I can explain how merge sort splits and recombines a list.
- I know how quick sort picks a pivot and partitions around it.
- I can state the average time complexity of all five.
- I use `list.sort()` and `sorted()` in real code, and can say why.

## Try This
1. Trace one full pass of bubble sort on `[5, 2, 4, 1]` on paper.
2. Implement selection sort, then insertion sort, without looking.
3. Write merge sort recursively and test it on an already-sorted list.
4. Explain why quick sort degrades to O(n²) and what choice causes it.
5. Sort a list of dictionaries by one key using `sorted(..., key=...)`.
