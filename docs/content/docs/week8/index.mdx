Sorting is the standard worked example for algorithm design, because there are
many correct answers and they are not equally good. Five algorithms, all solving
the same problem, with performance ranging from unusable to excellent.

You will never write these in production. You will be asked about them, and more
usefully, they teach you to read an algorithm and reason about its cost.

<Callout title="Before you start">
You need [Week 7](/docs/week7), plus [for Loops](/docs/week2/for-loops) and
[Lists](/docs/week3/lists). [Recursion](/docs/week4/recursion) shows up in merge
sort and quick sort.
</Callout>

## What you'll learn

- Read an algorithm and work out its time complexity
- Trace five sorting algorithms by hand, step by step
- Explain why divide-and-conquer beats the quadratic sorts
- Know why Python's built-in `sorted()` is the right answer in real code
