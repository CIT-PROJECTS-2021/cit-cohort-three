# Cryptography

Cryptography protects information by transforming it into a form that is hard
to read without a key.

<Callout type="info">
You don’t need to invent cryptography — use trusted libraries and standards.
</Callout>

## Key Terms
- **Plaintext**: readable message.
- **Ciphertext**: encrypted message.
- **Encryption**: converting plaintext to ciphertext.
- **Decryption**: converting ciphertext back to plaintext.

## Types of Cryptography
### Symmetric
Same key used for encryption and decryption.

Examples: AES, DES, Blowfish.

**Use cases**
- Encrypting files on disk
- Securing data between trusted systems

### Asymmetric
Different keys for encryption (public) and decryption (private).

Examples: RSA, Diffie‑Hellman, ECC.

**Use cases**
- Secure key exchange
- Digital signatures

<Steps>
<Step title="Encrypt">
Use a key to turn plaintext into ciphertext.
</Step>
<Step title="Transmit">
Send the ciphertext over an untrusted channel.
</Step>
<Step title="Decrypt">
Use the correct key to recover the original message.
</Step>
</Steps>

## Hash Functions
Hashing produces a fixed-length output from any input. Hashes are one-way and
used for integrity checks.

Examples: SHA‑256, SHA‑3, MD5 (legacy).

<Callout type="warning">
MD5 is fast but insecure. Use modern hashes like SHA‑256.
</Callout>

**Example with `hashlib`**
```python
import hashlib

text = "hello".encode("utf-8")
digest = hashlib.sha256(text).hexdigest()
print(digest)
```
**Expected output**
```
2cf24dba5fb0a30e26e83b2ac5b9e29e1b161e5c1fa7425e73043362938b9824
```

## Symmetric Encryption Example (Fernet)
Fernet provides authenticated symmetric encryption.

```python
from cryptography.fernet import Fernet

key = Fernet.generate_key()
f = Fernet(key)

token = f.encrypt(b"secret message")
print(token)

print(f.decrypt(token))
```

**Expected output (example)**
```
b'gAAAAABl...'
b'secret message'
```

## Asymmetric Encryption Example (RSA)
Asymmetric encryption uses a public key to encrypt and a private key to decrypt.

```python
from cryptography.hazmat.primitives.asymmetric import rsa, padding
from cryptography.hazmat.primitives import hashes

private_key = rsa.generate_private_key(public_exponent=65537, key_size=2048)
public_key = private_key.public_key()

message = b"hello rsa"
ciphertext = public_key.encrypt(
    message,
    padding.OAEP(
        mgf=padding.MGF1(algorithm=hashes.SHA256()),
        algorithm=hashes.SHA256(),
        label=None,
    ),
)

plaintext = private_key.decrypt(
    ciphertext,
    padding.OAEP(
        mgf=padding.MGF1(algorithm=hashes.SHA256()),
        algorithm=hashes.SHA256(),
        label=None,
    ),
)

print(plaintext)
```

**Expected output**
```
b'hello rsa'
```

## Digital Signature Example
Digital signatures prove that a message was created by the holder of a private key.

```python
from cryptography.hazmat.primitives.asymmetric import rsa, padding
from cryptography.hazmat.primitives import hashes

private_key = rsa.generate_private_key(public_exponent=65537, key_size=2048)
public_key = private_key.public_key()

message = b"verify me"

signature = private_key.sign(
    message,
    padding.PSS(
        mgf=padding.MGF1(hashes.SHA256()),
        salt_length=padding.PSS.MAX_LENGTH,
    ),
    hashes.SHA256(),
)

try:
    public_key.verify(
        signature,
        message,
        padding.PSS(
            mgf=padding.MGF1(hashes.SHA256()),
            salt_length=padding.PSS.MAX_LENGTH,
        ),
        hashes.SHA256(),
    )
    print("Signature valid")
except Exception:
    print("Signature invalid")
```

**Expected output**
```
Signature valid
```

## Password Hashing (with Salt)
Never store raw passwords. Use hashing with a random salt.

```python
import os
import hashlib

password = "hunter2".encode("utf-8")
salt = os.urandom(16)
hashed = hashlib.pbkdf2_hmac("sha256", password, salt, 100_000)

print(salt.hex())
print(hashed.hex())
```

**Expected output**
```
<random 32 hex chars>
<derived hash in hex>
```

## Integrity Check Example
```python
import hashlib

def sha256_file(path):
    h = hashlib.sha256()
    with open(path, "rb") as f:
        for chunk in iter(lambda: f.read(8192), b""):
            h.update(chunk)
    return h.hexdigest()

print(sha256_file("file.txt"))
```

**Expected output**
```
<sha256 hex digest>
```

## Beginner Guidance
<Callout type="tip">
Don’t build your own cryptography. Use trusted libraries and well‑known
algorithms.
</Callout>

## Mini Exercises
1. Hash two different strings and compare their digests.
2. Change one character and note how the hash changes.
3. Explain why hashes are good for password storage (but require salts).

## Common Mistakes
- Storing plaintext passwords instead of hashes.
- Using MD5 or SHA‑1 for security-sensitive data.
- Rolling your own encryption instead of trusted libraries.
