Logical operators combine boolean expressions.

<Callout type="info">
`and` and `or` short‑circuit: Python stops evaluating once the result is known.
</Callout>

## Operators
| Operator | Meaning | Example |
| --- | --- | --- |
| `and` | true if both operands are true | `x > 0 and y > 0` |
| `or` | true if either operand is true | `x > 0 or y > 0` |
| `not` | inverts truth value | `not is_valid` |

## Example
```python
x = True
y = False

print(x and y)  # False
print(x or y)   # True
print(not x)    # False
```

**Short‑circuit example**
```python
def is_valid():
    print("checked")
    return True

False and is_valid()  # is_valid() is not called
True or is_valid()    # is_valid() is not called
```

## Truth Tables
`and`
| A | B | A and B |
| --- | --- | --- |
| True | True | True |
| True | False | False |
| False | True | False |
| False | False | False |

`or`
| A | B | A or B |
| --- | --- | --- |
| True | True | True |
| True | False | True |
| False | True | True |
| False | False | False |

`not`
| A | not A |
| --- | --- |
| True | False |
| False | True |


## Rules

1. **`and` and `or` return one of their operands, not a boolean.** `0 or "hi"` is `"hi"`.
2. **Both short-circuit.** `and` stops at the first falsy operand, `or` at the first truthy one — so the right side may never be evaluated.
3. **`not` always returns a real boolean.**
4. **Precedence is `not` → `and` → `or`**, so `a or b and c` means `a or (b and c)`.
5. **They work on any value, not just booleans**, using the truthiness rules.
6. **Use `and`/`or` on single values, `&`/`|` on NumPy arrays and Pandas columns.** Mixing them up raises `ValueError` in [Pandas](/docs/week12/pandas).

## Common Mistakes
- Forgetting that `and`/`or` short‑circuit.
- Mixing `and` and `or` without parentheses.
- Using `not` with the wrong scope.
