Lists are ordered, mutable collections. They can hold mixed types and be
resized as needed.

<Callout type="info">
Lists are mutable, which makes them flexible but also easy to change by
accident. Be careful when passing lists between functions.
</Callout>

## Creating Lists
```python
numbers = [1, 2, 3]
mixed = ["Apple", 12, 45.7, False]
nested = ["Apple", ["Banana", "Cherry"], "Durian"]
```

## Accessing Items
```python
fruits = ["Apple", "Banana", "Cherry"]

print(fruits[0])   # Apple
print(fruits[-1])  # Cherry
```

**List length**
```python
print(len(fruits))  # 3
```

## Slicing
```python
letters = ["P", "y", "t", "h", "o", "n"]
print(letters[2:5])  # ['t', 'h', 'o']
print(letters[:3])   # ['P', 'y', 't']
print(letters[3:])   # ['h', 'o', 'n']
```

## Updating Items
```python
odd = [2, 4, 6, 8]
odd[0] = 1
odd[1:4] = [3, 5, 7]
print(odd)  # [1, 3, 5, 7]
```

## Adding Items
```python
fruits = ["Apple", "Banana"]
fruits.append("Cherry")
fruits.extend(["Durian", "Mango"])
fruits.insert(1, "Grape")
```

## Removing Items
```python
fruits = ["Apple", "Banana", "Cherry", "Durian"]
fruits.remove("Banana")
last = fruits.pop()
del fruits[0]
fruits.clear()
```

## Common Methods
| Method | Purpose |
| --- | --- |
| `append()` | add one item to end |
| `extend()` | add many items |
| `insert()` | insert at index |
| `remove()` | remove by value |
| `pop()` | remove by index (default last) |
| `clear()` | remove all items |
| `index()` | find first index |
| `count()` | count occurrences |
| `sort()` | sort list in place |
| `reverse()` | reverse in place |
| `copy()` | shallow copy |

<Callout type="tip">
Use `list.copy()` or slicing (`items[:]`) to avoid accidental shared references.
</Callout>

**Shallow copy example**
```python
original = [[1], [2]]
copy = original.copy()
copy[0].append(99)
print(original)  # [[1, 99], [2]] because inner lists are shared
```

## List Comprehensions
```python
powers = [2 ** x for x in range(5)]
odds = [x for x in range(10) if x % 2 == 1]
```

## Iteration
```python
for fruit in ["Apple", "Banana"]:
    print(fruit)
```

**Index + value**
```python
for index, fruit in enumerate(["Apple", "Banana"]):
    print(index, fruit)
```


## Rules

1. **Lists are ordered and mutable**, and may hold mixed types.
2. **Indexing starts at 0; negative indexes count from the end.** An out-of-range index raises `IndexError`.
3. **Slices exclude the end index and never raise `IndexError`.**
4. **`append()` adds one item; `extend()` adds each item of an iterable.** `append([1,2])` nests a list inside the list.
5. **`sort()`, `reverse()`, `append()`, and `extend()` return `None`.** `numbers = numbers.sort()` sets `numbers` to `None`.
6. **`remove()` deletes the first matching value and raises `ValueError` if absent; `pop()` deletes by index and raises `IndexError`.**
7. **Assignment does not copy.** `b = a` gives two names for one list. Use `a.copy()` or `a[:]`.
8. **A copy is shallow.** Nested lists are still shared — use `copy.deepcopy()` if that matters.
9. **Never add or remove items while iterating.** Loop over a copy instead.

## Common Mistakes
- Modifying a list while iterating over it.
- Confusing `append` and `extend`.
- Assuming a shallow copy duplicates nested lists.
