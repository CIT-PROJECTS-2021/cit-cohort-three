## Checklist
- I can choose between `if`, `for`, and `while`.
- I understand arithmetic, comparison, and logical operators.
- I can work with strings, lists, tuples, sets, and dictionaries.

## Try This
1. Write a loop that prints only even numbers from 1–20.
2. Use a dictionary to count word frequency in a sentence.
3. Write a list comprehension that squares numbers 1–5.
