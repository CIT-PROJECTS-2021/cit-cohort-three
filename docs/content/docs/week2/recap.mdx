## Checklist
- I can name the operator I need for a given job.
- I know the difference between `=` and `==`, and between `is` and `==`.
- I can write an `if` / `elif` / `else` chain and explain which branch runs.
- I can list the values Python treats as falsy.
- I can choose between a `while` loop and a `for` loop.
- I can use `break` and `continue` without losing track of the loop.

## Try This
1. Print the even numbers from 1 to 20 twice: once with `while`, once with `for`.
2. Write a guessing game that keeps asking until the answer is right.
3. Loop over `range(1, 101)` and stop at the first number divisible by both 7 and 9.
4. Predict the output of `5 // 2`, `5 % 2`, and `5 ** 2` before running them.
