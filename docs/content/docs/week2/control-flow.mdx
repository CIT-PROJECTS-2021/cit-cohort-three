Control flow is the order your code executes in. By default Python runs one line
after another, top to bottom. Control flow statements let you break that order:
run something *only sometimes*, or run it *many times*.

There are only three tools, and choosing between them is most of the skill.

<Callout type="info">
Most bugs in beginner code come from an incorrect condition or loop logic — not
from syntax. Read your conditions out loud to check they say what you meant.
</Callout>

## Which one do I need?

<Steps>
<Step title="Making a decision? Use if">
You have two or more paths and need to pick one. *"If the user is an adult, allow
access."* → [if Statements](/docs/week2/if-statements)
</Step>
<Step title="Have a collection? Use for">
You already know what you're looping over — a list, a string, a range of numbers.
*"For each student, print their name."* → [for Loops](/docs/week2/for-loops)
</Step>
<Step title="Don't know how many times? Use while">
You repeat until something changes, and you can't say in advance how long that
takes. *"Keep asking until the input is valid."* → [while Loops](/docs/week2/while-loops)
</Step>
</Steps>

Both loops can be steered mid-flight with
[`break` and `continue`](/docs/week2/break-and-continue).

## The shape of all of them

Every control flow statement follows the same two rules:

1. The header line ends with a colon `:`
2. The body is **indented** underneath it

```python
if temperature > 30:
    print("Hot")      # indented — part of the if
print("Done")         # not indented — always runs
```

Python uses indentation where other languages use `{ }`. This isn't a style
preference; it's the syntax. See [Python Syntax](/docs/week1/python-syntax).

## A quick taste of each

<Tabs items={['if', 'for', 'while']}>
<Tab value="if">
```python
x = 10

if x < 0:
    print("Negative")
elif x % 2 != 0:
    print("Positive and odd")
else:
    print("Even or zero")
```

Full details: [if Statements](/docs/week2/if-statements)
</Tab>
<Tab value="for">
```python
fruits = ["apple", "banana", "cherry"]

for fruit in fruits:
    print(fruit)
```

Full details: [for Loops](/docs/week2/for-loops)
</Tab>
<Tab value="while">
```python

counter = 1

while counter <= 5:
    total += counter
    counter += 1

print(total)  # 15
```

Full details: [while Loops](/docs/week2/while-loops)
</Tab>
</Tabs>

## Rules

1. **Every control flow header ends with a colon `:`** and owns the indented block beneath it.
2. **A block must contain at least one statement.** Use `pass` as a placeholder.
3. **Conditions are evaluated as booleans.** Any value works — see the truthiness rules on [if Statements](/docs/week2/if-statements).
4. **`for` needs something iterable**; `while` needs something that becomes false. Using the wrong one is legal but usually a sign the logic is off.
5. **`break` and `continue` are only valid inside a loop.** Using either outside one is a `SyntaxError`.

## Common Mistakes

- Forgetting the colon `:` at the end of the header line.
- Inconsistent indentation inside a block — Python raises `IndentationError`.
- Forgetting to update the loop variable in a `while` loop, so it never ends.
- Writing a condition that is always `True` or always `False`.
