# Tuples

Tuples are ordered and immutable collections.

<Callout type="info">
Use tuples when data shouldn’t change, such as coordinates or configuration
pairs.
</Callout>

## Creating Tuples
```python
empty = ()
numbers = (1, 2, 3)
mixed = (1, "a", 2.5)

packed = "cat", "dog", "rabbit"
cat, dog, rabbit = packed
```

Single-item tuples need a trailing comma:
```python
single = (1,)
```

**Tuple unpacking**
```python
point = (10, 20)
x, y = point
print(x, y)  # 10 20
```

## Accessing Items
```python
t = (10, 20, 30, 40)

print(t[0])   # 10
print(t[-1])  # 40
print(t[1:3]) # (20, 30)
```

## Immutability
```python
t = (1, 2, 3)
# t[0] = 9  # TypeError
```

If a tuple contains a mutable object (like a list), that inner object can be
changed:

```python
t = (1, [2, 3])
t[1][0] = 99
print(t)  # (1, [99, 3])
```

## Common Methods
```python
t = ("a", "p", "p", "l", "e")
print(t.count("p"))  # 2
print(t.index("l"))  # 3
```

## Membership and Iteration
```python
t = (1, 2, 3)
print(2 in t)  # True

for item in t:
    print(item)
```

## When to Use Tuples
- Fixed collections that should not change.
- Keys in dictionaries (tuples are hashable if they contain only immutable items).


## Common Mistakes
- Forgetting the trailing comma for single‑item tuples.
- Trying to modify tuple elements.
- Confusing tuples with lists.
