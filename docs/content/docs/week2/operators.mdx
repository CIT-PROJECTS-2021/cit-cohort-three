Operators are special symbols that perform computations on values (operands).

<Callout type="info">
When expressions look confusing, add parentheses to make the order clear.
</Callout>

## Operator Groups
- Arithmetic
- Comparison
- Logical
- Assignment
- Identity
- Membership
- Bitwise

## Rules

1. **Every operator needs the right number of operands.** Most are binary (`a + b`); `not`, unary `-`, and `~` are unary.
2. **Precedence decides evaluation order**, not left-to-right reading. Roughly: `**` → unary `-` → `* / // %` → `+ -` → comparisons → `not` → `and` → `or`.
3. **Parentheses override precedence** and are always allowed. When in doubt, add them.
4. **Most operators are left-associative; `**` is right-associative.** `2 ** 3 ** 2` is `512`, not `64`.
5. **Operators are type-sensitive.** `+` concatenates strings and lists but raises `TypeError` between a string and a number.
6. **Comparison and logical operators return booleans; arithmetic operators return numbers.**

## Common Mistakes
- Ignoring operator precedence and getting unexpected results.
- Mixing comparison and assignment (using `=` instead of `==`).
- Overusing complex expressions instead of adding parentheses.
