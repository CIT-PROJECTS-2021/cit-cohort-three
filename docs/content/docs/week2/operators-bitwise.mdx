Bitwise operators act on operands as if they were strings of binary digits.

<Callout type="info">
Bitwise operators are most useful for low‑level tasks, flags, and performance
optimizations. You won’t use them often as a beginner.
</Callout>

## Operators
| Operator | Meaning | Example |
| --- | --- | --- |
| `&` | bitwise AND | `x & y` |
| `|` | bitwise OR | `x | y` |
| `^` | bitwise XOR | `x ^ y` |
| `~` | bitwise NOT | `~x` |
| `<<` | shift left | `x << 2` |
| `>>` | shift right | `x >> 2` |

## Example
```python
x = 10  # 1010
y = 4   # 0100

print(x & y)   # 0
print(x | y)   # 14
print(x ^ y)   # 14
print(~x)      # -11
print(x << 2)  # 40
print(x >> 2)  # 2
```

## Note
Python does not have the `>>>` operator (unsigned right shift).


## Rules

1. **Bitwise operators work on integers only.** Applying them to a float raises `TypeError`.
2. **They operate on the binary representation**, two's complement, with conceptually infinite sign bits.
3. **`^` is XOR, not exponentiation.** Exponentiation is `**`.
4. **`~x` equals `-x - 1`**, so `~5` is `-6`.
5. **`<<` and `>>` shift by whole bits.** A negative shift count raises `ValueError`.
6. **`x << n` multiplies by `2**n`; `x >> n` floor-divides by `2**n`.**
7. **Bitwise operators bind tighter than comparisons but looser than arithmetic**, so parenthesise when mixing: `(x & 1) == 0`.

## Common Mistakes
- Using bitwise operators when logical operators are intended.
- Not understanding binary representation before using bitwise ops.
- Expecting `>>>` to work in Python.
