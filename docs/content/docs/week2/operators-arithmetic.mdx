Arithmetic operators perform mathematical operations.

<Callout type="info">
Use `//` when you want whole-number division and `%` when you need the remainder.
</Callout>

## Operators
| Operator | Meaning | Example |
| --- | --- | --- |
| `+` | addition | `5 + 3` |
| `-` | subtraction | `5 - 3` |
| `*` | multiplication | `5 * 3` |
| `/` | division (float) | `5 / 2` |
| `//` | floor division | `5 // 2` |
| `%` | remainder | `5 % 2` |
| `**` | exponentiation | `5 ** 2` |

## Example
```python
x = 15
y = 4

print(x + y)   # 19
print(x - y)   # 11
print(x * y)   # 60
print(x / y)   # 3.75
print(x // y)  # 3
print(x % y)   # 3
print(x ** y)  # 50625
```

## Use Cases

- Use `//` for pages or groups — 25 items, 4 per page.
- Use `%` to test divisibility — `n % 2 == 0` for even.
- Use `%` to wrap a value into a range, as the
  [Caesar cipher](/docs/week8/caesar-cipher) does with `% 26`.

## Precedence
1. Parentheses `()`
2. Exponentiation `**`
3. Multiplication, division, floor division, modulo `* / // %`
4. Addition, subtraction `+ -`

```python
print(((5 + 4) / 3) * 2)  # 6.0
```


## Rules

1. **`/` always produces a `float`.** Use `//` when you want an `int`.
2. **`%` takes the sign of the right operand** in Python, so `-7 % 3` is `2`, not `-1`.
3. **`/`, `//`, and `%` raise `ZeroDivisionError` on a zero right operand.**
4. **`**` is exponentiation, not `^`.** `^` is [bitwise XOR](/docs/week2/operators-bitwise).
5. **`+` and `*` are overloaded for sequences.** `"ab" * 3` repeats, `[1] + [2]` concatenates — but `"1" + 1` raises `TypeError`.
6. **Mixing `int` and `float` produces a `float`.**

## Common Mistakes
- Using `/` when you need whole numbers (use `//`).
- Assuming floats are always exact.
- Forgetting `%` returns the remainder.
- Expecting `5 / 2` to be `2` — it's `2.5`. Use `//` for whole numbers.
- Relying on exact decimal results from floating-point arithmetic.
