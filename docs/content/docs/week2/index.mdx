Week 1 gave you values. This week you make programs that *decide* and *repeat*,
and you meet the containers Python uses to hold groups of values.

<Callout title="Before you start">
You should be comfortable with [Variables](/docs/week1/variables) and
[Numbers](/docs/week1/numbers) from [Week 1](/docs/week1).
</Callout>

## What you'll learn

- Branch on a condition with `if` / `elif` / `else`
- Repeat work with `for` and `while`, and steer loops with `break` / `continue`
- Use every category of Python operator, and know which one you need
- Choose between a list, tuple, set, and dictionary for a given job
