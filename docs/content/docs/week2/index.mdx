Week 1 gave you values. This week you combine them and act on the result: first
the operators that compare and calculate, then the statements that branch and
repeat.

Operators come first on purpose. An `if` statement is only as useful as the
condition inside it, and that condition is built from comparison and logical
operators.

<Callout title="Before you start">
You should be comfortable with [Variables](/docs/week1/variables) and
[Numbers](/docs/week1/numbers) from [Week 1](/docs/week1).
</Callout>

## What you'll learn

- Every category of Python operator, and which one you need when
- Branch on a condition with `if`, `elif`, and `else`
- Repeat work with `while` and `for`
- Steer a loop from inside it with `break` and `continue`

## Operators

Start with the [Operators overview](/docs/week2/operators), then read arithmetic,
comparison, and logical in order. Those three carry the rest of the week. The

## Control flow

`while` comes before `for` here. A `while` loop is just an `if` that keeps going,
so it follows straight on from the previous page. A `for` loop needs something to
iterate over, which is where [Week 3](/docs/week3) picks up.
