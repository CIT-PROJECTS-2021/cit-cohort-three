Assignment operators are used to assign values to variables.

<Callout type="tip">
Use compound operators like `+=` to update a variable in place and keep code
compact.
</Callout>

## Operators
| Operator | Example | Equivalent to |
| --- | --- | --- |
| `=` | `a = 5` | `a = 5` |
| `+=` | `a += 5` | `a = a + 5` |
| `-=` | `a -= 5` | `a = a - 5` |
| `*=` | `a *= 5` | `a = a * 5` |
| `/=` | `a /= 5` | `a = a / 5` |
| `%=` | `a %= 5` | `a = a % 5` |
| `//=` | `a //= 5` | `a = a // 5` |
| `**=` | `a **= 5` | `a = a ** 5` |
| `&=` | `a &= 5` | `a = a & 5` |
| `|=` | `a |= 5` | `a = a | 5` |

## Example
```python
x = 10
x += 3
x *= 2
print(x)  # 26
```


## Rules

1. **`=` assigns; it is a statement, not an expression.** You cannot use it inside an `if`.
2. **Augmented assignment requires the variable to already exist.** `x += 1` on an undefined `x` raises `NameError`.
3. **`x += y` is not always `x = x + y`.** On a list, `+=` mutates in place and affects every other name pointing at it.
4. **Multiple assignment unpacks left to right** and the counts must match: `a, b = 1, 2, 3` raises `ValueError`.
5. **Chained assignment binds all names to the same object.** `a = b = []` gives both names one shared list.
6. **The walrus `:=` assigns inside an expression** and always needs parentheses in a condition: `if (n := len(s)) > 3:`.

## Common Mistakes
- Overwriting variables unintentionally.
- Using `=` in a condition instead of `==`.
- Forgetting that `+=` modifies the variable in place.
